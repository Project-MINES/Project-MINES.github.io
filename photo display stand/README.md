Photo Display Stand (V1)

이 폴더에는 V1 로컬 저장소 기반의 사진 전시대 단일 파일 React 컴포넌트 스캐폴드가 포함되어 있습니다.

- 핵심: localStorage(key: 'photoExhibitionData') 사용, FileReader로 이미지 -> Base64 저장, Flip Card, 감정 선택 필수
- Tailwind CSS 유틸리티 클래스만 사용하도록 설계되어 있습니다.

사용시 주의: 이 스캐폴드는 React 환경(예: Vite 또는 Create React App)과 Tailwind 설정이 되어 있어야 정상 동작합니다.
